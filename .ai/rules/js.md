# Js

## Respect both control panel frontend stacks
The control panel has an Inertia/Vue stack and a legacy jQuery stack. Use `resources/js/cp.ts` for modern pages and `resources/js/legacy.ts` only to load legacy behavior.

## Use repository frontend tooling
Use `vp` commands. Check with `vp check`, build with `vp build`, and regenerate Wayfinder with `./vendor/bin/testbench wayfinder:generate`.

## Reuse VueUse and generated types
Check VueUse before writing lifecycle-managed composables. PHP-derived TypeScript types belong in `resources/js/generated` and are regenerated by the transformer.

## Treat custom elements as native
Vue treats tags containing a hyphen as native custom elements. Let them pass through instead of registering them as Vue components.
