# Field Group

`<craft-field-group>` lays [Field](?path=/docs/form-controls-field--docs)s out on a twelve-column grid.

<Canvas of={FieldGroupStories.Default} sourceState="shown" />

Children take a full row by default, which is the right default for a form: full-width fields are the easiest to scan down.

## Widths

A `width-*` class on a child gives it a fraction of the row:

<Canvas of={FieldGroupStories.Widths} sourceState="shown" />

The available fractions are `width-25`, `width-33`, `width-50`, `width-66`, and `width-75` — quarters, thirds, and halves of the twelve columns.

## Separated Columns

`separated` widens the gap between columns and draws a hairline down the middle of it, between fields that share a row. Element edit forms use it, so side-by-side fields read as separate columns:

<Canvas of={FieldGroupStories.Separated} sourceState="shown" />

The hairlines follow the layout: when a row wraps as the group narrows, or a field is hidden, the fields that no longer share a row lose theirs. Set `--c-field-group-separator-spacing` to change the space on each side of a hairline, for example to match the padding of the pane around the group.

## Container Queries, Not Media Queries

The breakpoints respond to the width of the group itself, not the viewport.

That means a group inside a narrow pane stacks even on a wide screen:

<Canvas of={FieldGroupStories.NarrowContainer} sourceState="shown" />

This is what you want for a component that has no idea where it will be placed — a form in a slideout, a modal, or a narrow sidebar gets a sensible layout without anyone configuring it.

Between roughly 25rem and 50rem, `width-25` widens to a half rather than collapsing straight to full, so a row of four short fields becomes two rows of two.

## In PHP

In a Craft control panel screen, or a plugin's `settingsUi()`, describe the UI with `CraftCms\Cms\Ui\Ui` instead of writing markup.
Each `Ui` and `CraftCms\Cms\Ui\Nodes\Group` lays its fields out on a field group, and fields set their column widths with `width()`:

```php
use CraftCms\Cms\Ui\Controls\Number;
use CraftCms\Cms\Ui\Enums\FieldWidth;
use CraftCms\Cms\Ui\Nodes\Field;
use CraftCms\Cms\Ui\Ui;

Ui::make()
    ->addGroup('Dimensions', [
        Field::make('Width', Number::make('width')->min(1)->suffix('px'))
            ->width(FieldWidth::Half),
        Field::make('Height', Number::make('height')->min(1)->suffix('px'))
            ->width(FieldWidth::Half),
    ]);
```

A group adds a heading over its fields, and doesn't change their paths.
Call `asField()` on a `Group` when its inputs make up one field, so the label reads as a field label rather than a heading.

## Accessibility

The group is layout only. It has no role or name, so a screen reader doesn't hear the fields as a group.

- **Name related fields with a fieldset.** When several fields answer one question, such as a date and a time, wrap them in a `craft-field` with `fieldset` so the group has a name. For a set of options, use `craft-checkbox-group` or `craft-radio-group`.
- **Write children in reading order.** The grid places children in source order, so the order you write them in is the order they're read and tabbed through.
