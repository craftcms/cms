# Nav Item

`<craft-nav-item>` is one entry in the control panel's navigation.

<Canvas of={NavItemStories.Default} sourceState="shown" />

Items belong inside a [Nav List](?path=/docs/components-nav-list--docs), which supplies the list semantics that make the group announce as a list with a count rather than as a run of loose links.

## Collapsed Navigation

`icon-only` collapses the item to its icon. The label is still announced, so the item keeps its name — and a subnav moves into a flyout rather than disappearing, which is what keeps the children reachable at any width.

## Accessibility

An item with `href` is a link, so it is focusable and activates on Enter without help. Without `href`, set `button` only for an item that performs an action on the current page, such as switching the element source or collapsing the nav, and listen for `click` on the item. Anything that goes to a URL needs `href`, even when a script handles the visit.

A few things are worth attention:

- **Every item needs label text, including `icon-only` ones.** `icon-only` hides the label visually, not from assistive technology: it becomes the row's accessible name and its tooltip. Do not "help" by removing the label.
- **Set `current` and `active` to match the page.** The item turns them into `aria-current`: `page` for the link to the page you're on, `true` for its ancestors and for a current button. The color alone does not announce anything, so leaving them off leaves screen reader users without the selection.
- **A heading over a subnav is only visual.** A `group` item, or one whose label is styled text, isn't announced as a heading. Keep heading text short and the items under it self-explanatory.
- **Controls in the `actions` slot need their own names**, for example `aria-label="Customize sources"`, since they usually show only an icon.
