# Text Expander

`<craft-text-expander>` offers suggestions as a person types a trigger character.

<Canvas of={TextExpanderStories.TextInput} sourceState="shown" />

It wraps an input or textarea and watches for triggers — `@` for a user, `#` for an entry — then offers matches inline, without the person leaving the field.

## In PHP

In a Craft control panel screen, or a plugin's `settingsUi()`, describe the UI with `CraftCms\Cms\Ui\Ui` instead of writing markup.
`Text` and `Textarea` controls take text expander triggers with `textExpanderTriggers()`:

```php
use CraftCms\Cms\Ui\Controls\Text;
use CraftCms\Cms\Ui\Nodes\Field;
use CraftCms\Cms\Ui\Ui;

Ui::make([
    Field::make('Title Format', Text::make('titleFormat')
        ->textExpanderTriggers([
            [
                'trigger' => '{',
                'boundary' => 'anywhere',
                'label' => 'Variables',
                'options' => [
                    ['label' => 'Title', 'value' => '{title}'],
                    ['label' => 'Post Date', 'value' => '{postDate|date}'],
                ],
            ],
        ])),
]);
```

Each trigger has the `trigger` character, its `boundary`, and either its `options` or a `source`, a controller action that suggestions are fetched from as the person types.
For object template variables, `CraftCms\Cms\Cp\SelectOptions::getObjectTemplateTextExpanderTriggers()` builds the triggers for you.

## Accessibility

This is a combobox pattern layered onto a free-text field, and the announcement is the part that carries it.

The suggestion list is wired to the input, so arrowing through options announces each one while focus stays in the field. A live region announces "Loading" while an asynchronous source fetches, "No suggestions" when nothing matches, and that suggestions collapsed when the list closes.

The expander binds to an existing input or textarea and adds no label of its own, so give the field a visible label. Nothing on screen shows that suggestions exist until a trigger is typed, so name the trigger characters in the label or help text — "Mention a user with @", for example. The stories do this in their labels.

Because suggestions arrive as a person types, keep the option text short and put the distinguishing part first. A list where every entry starts with the same words is a list nobody can navigate by ear.
