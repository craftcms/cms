# Icon

`<craft-icon>` renders an SVG icon, fetched by name from the control panel's published icon assets.

<Canvas of={IconStories.Default} sourceState="shown" />

It is the icon primitive the rest of the library builds on — buttons, action items, callouts, and chips all render one internally when given an icon name.

## Sizing and Colour

Icons inherit `currentColor` and are sized in `em`, so they take the colour and size of the text around them.
That is deliberate: an icon beside a label should match that label without either being set explicitly.

<Canvas of={IconStories.InheritsText} sourceState="shown" />

To change an icon's size, change the font size of what contains it.

## Naming an Icon

`name` resolves against a `family` and a `variant`, defaulting to `classic` and `solid` — the set the control panel's own icons come from.

A name that does not resolve leaves the icon empty rather than rendering a placeholder, and logs the failure. Check the name against the icon set if one goes missing.

## Your Own Artwork

Slot an `<svg>` to render something the icon set does not cover:

<Canvas of={IconStories.SlottedSvg} sourceState="shown" />

Slotted content wins: while the slot has content, no named icon is fetched. Give the SVG `fill="none"` and `stroke="currentColor"` if you want it to inherit colour the way a named icon does.

## Badges

`appearance="badge"` draws the icon on a coloured disc, for a marker that has to read as a status rather than as decoration:

<Canvas of={IconStories.Badge} sourceState="shown" />

It defaults the disc to the warning colour. Set `data-color` for any other.

## Accessibility

**An icon is decorative unless you say otherwise.** Without a `label` it is `aria-hidden`, so it adds nothing to what a screen reader announces:

<Canvas of={IconStories.Labelled} sourceState="shown" />

Setting `label` makes it `role="img"` with that accessible name.

The rule of thumb is what the icon sits beside:

- **Beside text that already says it** — leave the label off. A trash icon next to the word "Delete" announced as "Delete Delete" is worse than one that is silent.
- **On its own** — it needs a label, because nothing else names it. This is the usual case inside an icon-only button.
