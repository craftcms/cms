# Dialog

`<craft-dialog>` is a modal dialog.

<Canvas of={DialogStories.Default} sourceState="shown" />

Being modal, it takes focus and blocks the page behind it. That is a strong thing to do to someone, so reach for it only when they genuinely have to deal with something before continuing — a destructive confirmation, a required choice.

For anything less, a [Popover](?path=/docs/components-popover--docs) or an inline [Callout](?path=/docs/components-callout--docs) interrupts less.

## Opening and Closing

Set the `open` attribute to show it.

The attribute is `open`, but the property is **`opened`**, not `open`. The two stay in sync in both directions.

```js
dialog.setAttribute('open', ''); // shows it
dialog.opened = false; // hides it
```

Any descendant carrying `data-dialog="close"` closes the dialog when clicked, so a close button needs no wiring.

## Content

Default-slot children are the body; `slot="footer"` children are right-aligned below it, which is where actions go.

## Resizing

Set `resizable` to let people resize the dialog from its right and bottom edges, or both at once from their corner, which also takes the keyboard. The dialog stays centered as it's resized, within its maximum size. See [Resize Grips](?path=/docs/components-resize-grips--docs).

## Accessibility

The dialog renders inside a native `<dialog>`, so the browser supplies the modal behavior — the focus trap, the inert background, and Escape to dismiss.

Two things stay with you:

- **Name it.** Set `label`. It renders as the header's heading and names the dialog, which is otherwise announced only as "dialog".
- **Give it a way out that is not Escape.** Escape works, but a visible close or cancel control is what makes that discoverable.
