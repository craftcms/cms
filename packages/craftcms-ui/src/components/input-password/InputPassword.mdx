# Input Password

`<craft-input-password>` is a password field with a button to reveal what has been typed.

<Canvas of={InputPasswordStories.Default} sourceState="shown" />

The button toggles the field between `password` and `text`, and renames itself "Show" or "Hide" as it goes, so the button always says what it is about to do.

## Everything Else

It is [Input](?path=/docs/form-controls-text-controls-input--docs) underneath, so the whole base surface applies — labeling, the width inference around `maxlength`, `size`, and the slots.

## Accessibility

The reveal button carries a real label that changes with the state, so it is announced as "Show" or "Hide" rather than as an unnamed button.

Revealing a password puts it on screen in plain text.
That is the point of the control, but it means the button should stay where the person expects it and should not be triggered by anything other than a deliberate press.

Set `autocomplete="current-password"` on a sign-in form and `autocomplete="new-password"` where a password is being set, so password managers fill the right field.
Don't block paste, and don't ask for a password to be retyped from memory without allowing paste or a password manager.
State the password requirements in help text before the form is submitted.
