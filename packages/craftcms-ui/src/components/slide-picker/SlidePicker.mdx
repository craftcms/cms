# Slide Picker

`<craft-slide-picker>` picks a number from a small set of steps.

<Canvas of={SlidePickerStories.Default} sourceState="shown" />

Use it where the range is short and every step is meaningful — a column count, a level, a size. For a continuous range use [Slide Rule](?path=/docs/form-controls-slide-rule--docs); for an exact number a person already knows, a number input is faster than dragging.

## Posting a Value

Give it a `name` and it posts with the form the way a native input does: `new FormData(form)` reads it, and `form.reset()` puts back the value it started with. Set the starting value with `value`.

`readonly` and `disabled` differ in what they post: a read-only control still submits its value, a disabled one is left out of submission entirely.

It emits the same events a radio group does. Every step is a commit, so `change` follows each `input`:

```js
picker.addEventListener('change', () => {
  console.log(picker.value);
});
```

## Announcing the Value

A slider's value is a number, and a number on its own rarely means anything.

`value-unit` supplies the units, so the control announces "3 columns" rather than "3":

```html
<craft-slide-picker value-unit="columns"></craft-slide-picker>
```

The picker puts a space before a unit that starts with a letter, so don't include one. A symbol such as `%` is attached to the number: `value-unit="%"` announces "100%".

When a unit is not enough, `valueLabel` formats the announced value however you like. It is a property rather than an attribute, so bind it with `.valueLabel`.

## Accessibility

The control is a slider and a Lion field, like [Input](?path=/docs/form-controls-text-controls-input--docs). The slider takes its name and description from one of these:

- **Its own label.** Set `label`, and add help text to describe the slider. Keep the label visible, so people know what the slider sets and can name it by voice. When something next to the picker already says what it sets, add `label-sr-only` to hide the label visually.
- **A surrounding [Field](?path=/docs/form-controls-field--docs).** Leave `label` off. The field's label names the slider, and its instructions and errors describe it.
- **A table column heading.** In a table cell, point `labelled-by` at the heading, and `described-by` at anything that describes the slider.

Without one of these, the slider has no name.

Set `value-unit` or `valueLabel` whenever the number alone doesn't say what it counts.

Sliders are hard to operate precisely with a pointer and easy with a keyboard, so the arrow-key behavior is not a fallback — it is how many people will use it. Keep the step count low enough that arrowing to a value is quick. There's no Page Up or Page Down.
