# Badge Indicator

`<craft-badge-indicator>` marks something as new or changed, with an optional count.

<Canvas of={BadgeIndicatorStories.Dot} sourceState="shown" />

It attaches to whatever it sits beside — a nav item, a tab, a button — and says only "there is something here".

<Canvas of={BadgeIndicatorStories.Numbered} sourceState="shown" />

A count above `max` (99 by default) is shown as `99+`. For a tally rather than a nudge, such as how many elements a source has, set `max` to `Infinity` and the marker grows to fit the whole number, formatted for the page's language:

<Canvas of={BadgeIndicatorStories.Uncapped} sourceState="shown" />

## Not the Same as Badge

[Badge](?path=/docs/components-badge--docs) is a pill with a label, naming a state in place. This is a marker that draws attention to something else.

If the thing needs naming, use a badge. If it needs pointing at, use this.

## Overlapping an Icon

When the dot sits on top of an icon or another badge, cut a gap out of what's beneath it instead of ringing the dot in a surface color, so the gap stays right over every background and hover state. Include `badgeIndicatorCutoutStyles` in the rule for the element beneath, and set `--c-badge-indicator-cutout-x` and `--c-badge-indicator-cutout-y` to the dot's center in that element's box:

```ts
import {badgeIndicatorCutoutStyles} from '@craftcms/ui/components/badge-indicator/badge-indicator';

css`
  .trigger__icon--indicated {
    --c-badge-indicator-cutout-x: calc(100% - 2px);
    --c-badge-indicator-cutout-y: -2px;
    ${badgeIndicatorCutoutStyles}
  }
`;
```

## Accessibility

A bare dot conveys nothing — it is a colored shape with no text.

`alt-text` is what gives it meaning, and it is worth setting whenever the badge is not immediately beside text that already explains it.

For a count, `badge-count-suffix` supplies the units, because a number alone is ambiguous:

```html
<craft-badge-indicator badge-count="3" badge-count-suffix="unread messages">
</craft-badge-indicator>
```

Announced as "3 unread messages" rather than "3", which could be anything.

When the marker sits on a button or link, make its meaning part of that control, so it's announced when the control is reached. Put the text inside the control's label, or reference it with `aria-describedby`.

The marker has no live region. If the count changes while the page is open and the change matters, announce it through a status message of your own, such as a `role="status"` region, rather than expecting the new number to be read.

Use `inverse` only on a dark or colored surface. On the default surface its fill is too light to stand out.
