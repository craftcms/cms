# Tab

`<craft-tab>` is a single trigger within a [Tabs](?path=/docs/components-tabs--docs) strip.

There are no stories here because a tab outside a strip controls nothing. See the [Tabs](?path=/docs/components-tabs--docs) page for working examples.

```html
<craft-tabs>
  <craft-tab slot="tab">Content</craft-tab>
  <div slot="panel">…</div>
</craft-tabs>
```

## Deliberately Thin

The tab owns almost nothing. [Tabs](?path=/docs/components-tabs--docs), via Lion, assigns it an `id`, `role="tab"`, `aria-controls`, `aria-selected`, and `tabindex`, and toggles `selected` as the selection moves.

The only state the tab owns is `disabled` — and even that is honoured by the strip, which skips disabled tabs during arrow-key navigation.

This is why `selected` is not something to set yourself: the strip will overwrite it. Set `selectedIndex` on the strip instead.

## External Panels

`controls` names a panel elsewhere in the document by id, for strips whose panels cannot be slotted alongside their tabs.

That is the escape hatch for a server-rendered field layout, where the tab bar sits in the page header and the sections sit inside a pane. Without it, tabs and panels have to be siblings.

## Styling

The tab is padded in `em`, so it scales with whatever font size it inherits — which is how the strip's `size` resizes every tab without touching any of them.

The selected indicator's geometry comes from custom properties the strip sets according to its `placement`. Override them to reposition the indicator; see the API table for the full set.
