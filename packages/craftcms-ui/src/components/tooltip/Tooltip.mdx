# Tooltip

`<craft-tooltip` is just a wrapper for [Web Awesome's `<wa-tooltip>`](https://webawesome.com/docs/components/tooltip) element so all of the options and properties of `<wa-tooltip>` can be used with `<craft-tooltip>`.
