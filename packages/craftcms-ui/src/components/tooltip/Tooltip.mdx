# Tooltip

`<craft-tooltip>` shows contextual text for an external trigger element referenced by id via the `for` attribute. It is built on [Lion's tooltip/overlay system](https://lion.js.org/components/tooltip/overview/) and supports `placement` (Popper placement strings) and `trigger` (`hover focus`, `click`, or `manual`). It emits `craft-show`, `craft-after-show`, `craft-hide`, and `craft-after-hide` events.

## Accessibility

The content carries `role="tooltip"`, and the invoker references it with `aria-describedby`, or `aria-labelledby` when `invoker-relation="label"`. It shows on hover and on keyboard focus, and Escape dismisses it while the invoker has focus.

Because a tooltip describes its invoker by default, the invoker needs an accessible name of its own. An icon-only button still needs an `aria-label`, as `craft-field`'s translation indicator has.

Point `for` at an element that can take keyboard focus, such as a real `button`. Keyboard users never see a tooltip on anything else.
