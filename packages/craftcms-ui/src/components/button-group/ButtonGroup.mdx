# Button Group

`<craft-button-group>` joins related buttons into a single visual unit.

## Selection Mode

Given a `name`, the group becomes a set of toggle buttons, of which one is pressed at a time:

In this mode the group is form-associated and posts like any other field, so a segmented control does not need a hidden input beside it.

## Choosing Between Modes

Without a `name` the buttons are actions; with one they are toggle buttons, each announced as pressed or not, and each its own tab stop.

For a form setting that picks one value from a set of options, use a [radio group](?path=/docs/form-controls-choice-controls-radio-group--docs) with `buttons` instead. It looks the same, but it's announced as radios, and the arrow keys move the selection.

## Icon Buttons

A segmented control of icons is compact and easy to misread. Each button still needs a name — see [Icon](?path=/docs/components-icon--docs) — because the group announces the choice, not what each option means.
