# Truncate

`<craft-truncate>` shortens text that does not fit, and shows the whole of it in a tooltip.

<Canvas of={TruncateStories.Default} sourceState="shown" />

The tooltip only appears when the text is actually clipped:

<Canvas of={TruncateStories.FitsWithoutTooltip} sourceState="shown" />

That conditional behavior is the point. A tooltip repeating text already fully visible is noise, and one that never appears leaves clipped text unreadable.

## When to Reach for It

Where a value's length is outside your control and the space is not — a filename in a column, an entry title in a narrow sidebar.

Where you control the text, write it shorter. Truncation is a fallback for unpredictable content, not a substitute for editing.

## Accessibility

The full text remains available to assistive technology, so a screen reader announces the whole value rather than the clipped version.

The tooltip opens on hover, and on keyboard focus only when the content holds something focusable, such as a link. Clipped plain text can't take focus, and a tap doesn't open the tooltip, so keyboard and touch users can't read the rest of it. Clipped text a person cannot expand is text they cannot read, so where the full value matters, make the content a link or show the full value somewhere else, such as a detail view.

`disabled` keeps the clipping and drops the tooltip. Use it only where the full value is already shown nearby.
