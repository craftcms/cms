# Copy Attribute

`<craft-copy-attribute>` copies a value read from an element's attribute.

<Canvas of={CopyAttributeStories.Default} sourceState="shown" />

It exists for server-rendered markup, where the value to copy is already on an element in the page and passing it through a property would mean serializing it twice.

For a value you have in script, [Copy Button](?path=/docs/components-copy-button--docs) takes it directly and is simpler.

## Events

Like the copy button, it emits `craft-copy` on success and `craft-error` on failure — clipboard writes can be refused, and the interface should say so rather than appear to have worked.

## Accessibility

The chip's visible text is its `value`, and that text, followed by a hidden "Copy to clipboard", is its accessible name. It can't be given another name, so use it where the value says what it is, such as a field handle.

Like the copy button, it changes only its icon and tooltip when a copy succeeds or fails. Listen for `craft-copy` and `craft-error` and announce the result in a live region on the page.

`disabled` doesn't reach the copy button yet, so a disabled copy attribute can still be focused and copied.
