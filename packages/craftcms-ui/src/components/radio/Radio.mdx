# Radio

`<craft-radio>` is one option within a [Radio Group](?path=/docs/form-controls-choice-controls-radio-group--docs).

There are no stories on this page because a radio on its own has nothing to be exclusive against — its whole behavior is defined by the group it belongs to. See the [Radio Group](?path=/docs/form-controls-choice-controls-radio-group--docs) page for working examples.

```html
<craft-radio-group label="Propagation method">
  <craft-radio
    label="Only save to the site it was edited in"
    value="none"
  ></craft-radio>
  <craft-radio label="Save to all sites in the group" value="all"></craft-radio>
</craft-radio-group>
```

## What It Contributes

The radio carries the option's `label` and `value`. The group carries the name, the current value, and any validation.

Like [Checkbox](?path=/docs/form-controls-choice-controls-checkbox--docs), it keeps the `checked`, `disabled`, and `name` of a server-rendered input rather than resetting them when the component upgrades.

## Accessibility

Lion wires the label to the input. The group names the question with `role="radiogroup"` and its label, and the browser's native radio grouping — every option sharing the group's `name` — is what makes the arrow keys move between options.

That is one more reason not to use a radio outside a group: alone, it is a control a person can select but never deselect, with no siblings to move between and no question to answer.

Give every radio a visible label that says what choosing it means. Clicking the label selects the radio, so the label also enlarges its target.
