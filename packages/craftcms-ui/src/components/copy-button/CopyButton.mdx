# Copy Button

`<craft-copy-button>` copies a value to the clipboard.

<Canvas of={CopyButtonStories.Default} sourceState="shown" />

Use it beside a value worth taking away — a token, a URL, an ID. For a value shown in a field, [Input Copy](?path=/docs/form-controls-text-controls-input-copy--docs) pairs the two together and is usually the better fit.

## Events

The outcome is reported rather than assumed:

- `craft-copy` — the value reached the clipboard
- `craft-error` — it did not

Clipboard writes fail for reasons outside your control: permissions, an insecure context, a browser that declines. Listening for the failure is what lets the interface say so rather than appearing to have worked.

## Accessibility

The button's accessible name is its slotted content followed by a hidden "Copy to clipboard". `tooltip-label` only describes the button, so it doesn't change the name: put what's copied in the visible text ("Copy URL"), and don't repeat "Copy to clipboard" there.

A copy that succeeds silently is a copy a screen reader user cannot confirm. The button only changes its icon and tooltip, so listen for `craft-copy` and `craft-error` and announce the result in a live region on the page.

An icon-only copy button has no padding and is smaller than the 24px minimum target. Give it a larger box, or keep 24px clear around it.
