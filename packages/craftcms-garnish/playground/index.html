@craftcms/garnish playground

Interactive demos wired against the real source (../src/index.ts + ../src/compat.ts) with Vite HMR. Open the event-log panel (bottom-right) to watch events fire.

1. Modal

Construct new Modal() instances and drive their lifecycle. Every show / hide / fadeIn / fadeOut / escape event is piped into the log panel.

2. Focusable matcher & focus trap

The container below mixes focusable and non-focusable elements. Run the matcher to highlight what getFocusableElements / isKeyboardFocusable select, then open the focus-trap modal and press Tab / Shift+Tab to see cycling stay trapped.

Link with href (focusable) Link, no href (not focusable) Span tabindex=0 (keyboard focusable) Span tabindex=-1 (focusable, not keyboard) Plain span (not focusable)

3. Compat upgrade path

Calls installGarnishCompat(), then defines a subclass with the legacy Garnish.Modal.extend({ init, onShow }) API and a this.base() super-call — proving the legacy authoring contract works in the browser against the modern class Modal.

4. Draggable & resizable Modal

Modal's draggable / resizable options are now fully supported (they used to throw). Open each modal and drag/resize it live — dragStart / drag / dragStop events are piped into the log panel.

5. Standalone BaseDrag / DragMove

Free-floating boxes inside the bounded area below. The green boxes use new DragMove(box) directly; the blue box uses a raw new BaseDrag(box, {onDrag}) that sets left/top itself. Every dragStart / drag / dragStop fires into the log (drag events are throttled in the log to one line per gesture). The third green box is X-axis-locked ({axis: 'x'}).
